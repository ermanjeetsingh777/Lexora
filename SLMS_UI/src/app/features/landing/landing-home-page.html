Multi-tenant architecture

How Lexora maps your library network

Each institution is an isolated tenant with multiple branches. Branches host libraries in sequence, members map to one library each, and attendance is tracked at that library — with enterprise security across the full hierarchy.

Institution

Top-level tenant for your organisation.

Branch

Campus or city units under the institution.

Library

Reading halls with seats and resources.

Member

One member mapped to exactly one library.

Attendance

Daily check-in/out at the mapped library.
